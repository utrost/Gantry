This guide, its screenshots and the sample drawings are installed locally and work without an internet connection. Links to the full online guides and issue tracker need internet access.

Launch and find your files

Windows: the MSI installs Gantry for your Windows account. Open Gantry from the Start menu. Java is included. Open Gantry Help from the Start menu or choose Help > Getting Started (Offline)… in the application.

The default installation directory is %LOCALAPPDATA%\Gantry. The installer lets you choose another directory. Inside that directory, Gantry.exe is the GUI, gantry-cli.exe is the terminal command, and app\docs\index.html is this guide. Sample SVGs are under app\docs\samples.

Ubuntu: install the DEB and open Gantry from the applications menu. Native commands are under /opt/gantry/bin; this guide and samples are under /opt/gantry/lib/app/docs.

Portable JARs: install Java 17 or newer and run java -jar Gantry-@VERSION@.jar. The separate CLI JAR is for terminal use. You can download the matching documentation ZIP and extract it beside the GUI JAR.

Complete a first practice plot without hardware

  1. On first launch, choose Start guided practice. If the welcome is hidden, choose Help > Guided First Plot….
  2. Follow Machine Setup with the mock backend. This simulates a plotter and cannot move physical hardware.
  3. Check that the practice drawing sits inside the virtual bed.
  4. Choose Connect plotter, then Check before plotting. Follow the confirmations and start the mock plot.
  5. At each layer prompt, choose Pen ready — continue. Use Stop to cancel a plot.

Gantry should show Safe — nothing will move while disconnected. Loading or saving artwork does not connect a machine.

Try an included drawing

Use File > Open SVG or Vector Drawing… and select a sample from the folder listed above. To keep an original sample unchanged, save your editable work as a new .gantry project in your Documents folder.

  • Simple line: a small first drawing.
  • Three colour layers: practice selecting layers and changing pens.
  • Hatch and fill: try processing filled shapes.
  • Outlined text: text geometry without relying on installed fonts.

Save, reopen and export

File > Save Project… saves editable artwork, placement, layer selection and preparation settings in a .gantry file. Use Open Gantry Project… to return to it.

Export G-code (for plotter)… writes machine instructions for the selected layers and placement. Exporting does not send the file to a physical controller. Check machine geometry and pen settings before using exported G-code on hardware.

Unsaved edits create a recovery copy in your user profile. Settings, recent jobs and recovery persist across upgrades. Uninstalling Gantry preserves your profile and projects; your Documents folder is the recommended place for saved work.

The Windows profile is %APPDATA%\Gantry. On Linux it is $XDG_CONFIG_HOME/gantry, or ~/.config/gantry when that variable is unset.

Use the command line

The Windows installer includes gantry-cli.exe and its Java runtime. It has no desktop or Start menu shortcut. Open PowerShell and use:

& "$env:LOCALAPPDATA\Gantry\gantry-cli.exe" --help
& "$env:LOCALAPPDATA\Gantry\gantry-cli.exe" -i "$env:LOCALAPPDATA\Gantry\app\docs\samples\simple-line.svg" -o "$env:USERPROFILE\Documents\gantry-commands.json"

If you chose another installation directory, replace the installation path in these commands. Gantry does not change your PATH automatically. You can add your chosen installation directory to your user PATH manually if you want to run gantry-cli by name.

On Ubuntu:

/opt/gantry/bin/gantry-cli --help
/opt/gantry/bin/gantry-cli -i /opt/gantry/lib/app/docs/samples/simple-line.svg -o "$HOME/gantry-commands.json"

For a portable download, run java -jar Gantry-CLI-@VERSION@.jar --help. The native CLI requires no separate Java installation. Both forms prepare files; they do not connect a physical plotter.

Prepare for your real plotter

Before connecting hardware, set the machine's actual travel area, origin, pen-lift mode and feeds in Settings > Preferences…. Verify jogging directions with the pen raised. Use homing only with a properly configured controller and limit switches, then frame a small drawing before putting the pen down.

Mock success is useful workflow evidence but does not establish physical calibration or hardware readiness. Keep emergency stop or power within reach during a first physical test.

Get help

Choose Help > Copy Diagnostics when reporting a problem. Include your Windows or Linux version, Gantry version, controller, connection type, and what happened.
