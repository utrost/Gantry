This guide, its screenshots and the sample drawings are installed locally and work without an internet connection. Links to the full online guides and issue tracker need internet access.

Launch and find your files

Windows: the MSI installs Gantry for your Windows account. Open Gantry from the Start menu. Java is included. Open Gantry Help from the Start menu or choose Help > Getting Started (Offline)… in the application.

The default installation directory is %LOCALAPPDATA%\Gantry. The installer lets you choose another directory. Inside that directory, Gantry.exe is the GUI, gantry-cli.exe is the terminal command, and app\docs\index.html is this guide. Sample SVGs are under app\docs\samples.

Ubuntu: install the DEB and open Gantry from the applications menu. Native commands are under /opt/gantry/bin; this guide and samples are under /opt/gantry/lib/app/docs.

Portable JARs: install Java 17 or newer and run java -jar Gantry-@VERSION@.jar. The separate CLI JAR is for terminal use. You can download the matching documentation ZIP and extract it beside the GUI JAR.

Complete a first practice plot without hardware

  1. On first launch, choose Start guided practice. If the welcome is hidden, choose Help > Guided First Plot….
  2. The sample opens directly in simulation, without serial, axis or pen-actuator setup. It cannot move physical hardware.
  3. Check that the practice drawing sits inside the virtual bed.
  4. Choose Connect plotter, then Check before plotting. Follow the confirmations and start the mock plot.
  5. At each layer prompt, choose Pen ready — continue. Use Stop to cancel a plot.

During practice the top bar says Simulation • no physical hardware. Loading or saving artwork does not connect a machine.

Try an included drawing

Use File > Open SVG or Vector Drawing… and select a sample from the folder listed above. Review the physical preview and choose Open drawing. Use Add SVG to current drawing… to append instead; Cancel leaves your document unchanged. To keep an original sample unchanged, save your editable work as a new .gantry project in your Documents folder.

  • Simple line: a small first drawing.
  • Three colour layers: practice selecting layers and changing pens.
  • Hatch and fill: try processing filled shapes.
  • Outlined text: text geometry without relying on installed fonts.

Add a label, share pens and review overlap

Open / Add > Add text label… creates a label using the bundled single-stroke alphabet. Enter the text and letter height in millimetres; review its resulting width. Lowercase is drawn uppercase and unsupported characters are reported. Create quick artwork… also offers lines, rectangles and ellipses.

The new item is an artwork group: position it, assign its layer to a named pen, and include or exclude it normally. Save a .gantry project to retain the source. Reopen and use Edit > Artwork Groups… > Edit quick artwork… to change it. Creation and editing do not move a machine.

Edit > Manage Pens… lets layers share a named pen with a colour and physical width. Updating that pen updates all assigned layers. Undo/Redo, project reload and new job history preserve assignments. Pen width stays physical when artwork is resized; measure the actual line on your paper.

In Check before plotting, choose Analyze ink overlap… to inspect crossings and repeated passes in the prepared job. The analysis does not send machine commands. Its heatmap is geometric advice; it does not predict physical ink spread or drying, and does not add waits or reorder paths.

Predictable filled areas

In import processing or Adjust artwork processing, enable pen-width filling. For a region edit, choose Hatch Region Style and enable Use pen width + overlap. Effective stroke width is the measured line on your paper; nominal tip diameter is only a starting estimate.

spacing = width × (1 − overlap / 100). A 0.5 mm stroke at 20% overlap gives 0.4 mm spacing. Keep strokes inside boundary insets paths by the pen radius. Narrow features may disappear; the preview shows uncovered gaps in amber and overshoot in red. Coverage is a round-tip estimate.

Save named pen/paper profiles from the calculator. Edit > Pen/paper calibration swatch creates labelled 0/10/20/30% overlap patches and stroke samples, with dimensions and a workload preview. Creating artwork never moves the plotter; Check and Start are still required. Choose the best real-paper result and save its effective width/overlap. Profiles are stored beside settings in pen-paper-profiles.json.

Resize before filling, or regenerate after resizing: generated paths are static. Manual spacing and older projects retain their behavior. Cancel leaves the document unchanged; Undo restores generated geometry and pen width together.

Save, reopen and export

File > Save Project… saves editable artwork, placement, layer selection and preparation settings in a .gantry file. Ctrl+S reuses that path after the first save; Ctrl+Shift+S opens Save As. Use Open Gantry Project… to return to it.

File > Export Reviewed Job as SVG… saves included layers, placement and passes as a physical-size SVG. Export Reviewed Job as SVG Package… writes a ZIP with the combined SVG, one SVG per included layer and a README. Review any bed-clamping warning. These exports carry geometry and pen metadata, not machine commands, pen-change confirmations, refill motion or drying waits. Export feedback reports the destination and SVG count.

Export G-code (for plotter)… writes machine instructions for the selected layers and placement. Exporting does not send the file to a physical controller. Check machine geometry and pen settings before using exported G-code on hardware.

Unsaved edits create a recovery copy in your user profile. Settings, recent jobs and recovery persist across upgrades. Uninstalling Gantry preserves your profile and projects; your Documents folder is the recommended place for saved work.

Save/export results appear above the canvas. Unresolved error retains earlier failure details while a later success appears. Failed saves preserve dirty state and recovery; closing the recovery prompt keeps the copy for later.

Recent Plot Jobs reviews the stored drawing before movement. Return to artwork restores your editable document. Repeating uses stored paths/transforms/stations with your current pen-lift and speed settings.

The Windows profile is %APPDATA%\Gantry. On Linux it is $XDG_CONFIG_HOME/gantry, or ~/.config/gantry when that variable is unset.

Use the command line

The Windows installer includes gantry-cli.exe and its Java runtime. It has no desktop or Start menu shortcut. Open PowerShell and use:

& "$env:LOCALAPPDATA\Gantry\gantry-cli.exe" --help
& "$env:LOCALAPPDATA\Gantry\gantry-cli.exe" -i "$env:LOCALAPPDATA\Gantry\app\docs\samples\simple-line.svg" -o "$env:USERPROFILE\Documents\gantry-commands.json"

If you chose another installation directory, replace the installation path in these commands. Gantry does not change your PATH automatically. You can add your chosen installation directory to your user PATH manually if you want to run gantry-cli by name.

On Ubuntu:

/opt/gantry/bin/gantry-cli --help
/opt/gantry/bin/gantry-cli -i /opt/gantry/lib/app/docs/samples/simple-line.svg -o "$HOME/gantry-commands.json"

For a portable download, run java -jar Gantry-CLI-@VERSION@.jar --help. The native CLI requires no separate Java installation. Both forms prepare files; they do not connect a physical plotter.

Prepare for your real plotter

Before connecting hardware, set the machine's actual travel area, origin, pen-lift mode and feeds in Settings > Preferences…. Verify jogging directions with the pen raised. Use homing only with a properly configured controller and limit switches, then frame a small drawing before putting the pen down.

Mock success is useful workflow evidence but does not establish physical calibration or hardware readiness. Keep emergency stop or power within reach during a first physical test.

Get help

Choose Help > Copy Diagnostics when reporting a problem. Include your Windows or Linux version, Gantry version, controller, connection type, and what happened.
