# Gantry 1.0.0-rc.12

RC12 brings the post-RC11 preparation features, stronger simulator contracts and
packaged CLI fixes together for operator testing. Earlier releases are preserved.
This candidate is not a hardware-ready or stable-release declaration.

## Changes since RC11

- Export the reviewed job as SVG or a ZIP of combined and per-layer SVGs, with
  physical dimensions, pen metadata, inclusion/order and explicit destination/count
  feedback. Failed writes preserve the previous destination.
- Reuse named pens across layers, retaining name, colour and physical width through
  project reload, Undo/Redo, history and export.
- Add editable single-line stroke text, lines, rectangles and ellipses directly to
  a project. Physical placement, review and export use the existing job pipeline.
- Inspect advisory ink overlap across included layers and passes. This is geometric
  advice; it does not model ink spread, drying or executable drying waits.
- Mock Stop/cancellation freezes simulated motion at the reached point. Shared
  mock/production contracts and scripted serial faults strengthen lifecycle checks;
  reconnect also resets the production backend's cached pen state.
- Squiggle shading retains peripheral subjects and connected contours. Three real
  photographs and the Studio preset were visually reviewed. Results are recognizable
  stylizations with flat bands/detail limits and substantial pen-up travel, rather
  than a claim of photographic fidelity. Existing numeric defaults remain unchanged.
- The packaged CLI now includes PNG encoding. Unsupported/unavailable export formats
  fail explicitly; PNG/PDF writes are staged before replacement. PDF still requires
  a separate Apache FOP implementation and is not bundled.
- Saved vectorizer recipes retain effective settings, crop and style. Explicit
  command-line overrides take precedence when rerunning a recipe. Older metadata
  cannot recover parameters its original writer omitted.
- Batch conversion reports a nonzero status when any input fails, while retaining
  successful independent outputs. It rejects output collisions and source-image
  overwrites before writing. Use a separate directory for batch PNG output.

## Known blocker before public distribution

Visual review found [#93](https://github.com/utrost/Gantry/issues/93): under the
default origin settings, quick text is vertically reflected in the workspace,
and SVG/overlap views use a different page orientation. Automated save/export
checks passed but did not establish readable appearance. The candidate remains
a draft pending disposition; existing calibrated motion settings are unchanged.

## Downloads and verification

Windows x64 MSI and Linux x64 DEB include Java. Portable GUI/CLI JARs require
Java 17 or newer. Offline help, samples and SHA256SUMS accompany the downloads.
Native installer version is **1.0.12**; Windows installers remain unsigned.

Automated validation covers 597 Java tests, nine packaging tests, packaged CLI
workflows, real-image geometry/G-code preflight, Swing mock workflows, and native
Windows/Linux installation, upgrade and bundled-runtime checks. The upgrade
fixture uses current code with an RC11 identity; it does not emulate every
historical RC11 application schema.

See the [candidate evidence](https://github.com/utrost/Gantry/blob/main/docs/release-results/1.0.0-rc.12.md)
and [operator worksheet](https://github.com/utrost/Gantry/blob/main/docs/release-results/1.0.0-rc.12-operator.md)
for actual check status and remaining gates. Physical Windows 11/iDraw H A1,
native fractional scaling, the expert benchmark, a real quick-artwork task and
novice-participant acceptance remain open.
