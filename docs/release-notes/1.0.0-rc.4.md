# Gantry 1.0.0-rc.4

RC4 adds machine-settings import/export to the redesigned RC3 workspace.
Existing RC3 downloads remain unchanged.

- **Settings > Export Machine Settings...** saves a portable JSON profile containing
  serial connection, machine geometry and axis mapping, pen lift and speeds,
  soft limits, and watercolor stations.
- **Settings > Import Machine Settings...** accepts these profiles and existing
  Gantry `config.json` files. It validates the file and offers a review before
  applying it. Cancel leaves the current settings unchanged.
- Import requires a disconnected, idle machine. It preserves local appearance,
  simulation mode and preflight policy, saves atomically, and clears readiness.
  It does not connect or send movement commands.
- Watercolor station serialization preserves dip depth, dwell time and swirl
  radius, including older camel-case settings files.

Controller firmware settings, including GRBL `$100`/`$101` calibration registers,
are not included or written. Check the local serial port before connecting after
an import on a different computer.

Download `Gantry-1.0.0-rc.4-windows-x64.msi` or
`Gantry-1.0.0-rc.4-linux-x64.deb`. Both bundle Java. Windows packages are unsigned.
Portable GUI and CLI JARs require Java 17+. Native installer version `1.0.4`
allows upgrading from RC3 (`1.0.3`); Gantry reports `1.0.0-rc.4`.

Validation includes 504 Java tests, real Swing import/export/cancel/apply and
connected-import rejection, existing mock plotting/recovery workflows, and
cross-platform installer upgrade tests. Release CI supplies the detailed evidence.

The novice study, expert workflow review and fresh Windows 11 / iDraw H A1
acceptance of the redesigned machine interactions remain pending. Earlier RC2
hardware results do not establish hardware acceptance for this candidate.
