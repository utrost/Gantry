# Gantry 1.0.0-rc.8

RC8 keeps unavailable controls visible and clearly disabled. Previous release downloads remain unchanged.

- Disabled buttons retain muted backgrounds and labels in Dark and Light. Tooltips explain connection and busy-state restrictions.
- Jog, pen, Home and Frame controls reflect connection, active operations and controller availability. Raw-command entry cannot submit through Enter while disabled; technical recovery remains available in Alarm/Unknown states when no Gantry operation is active.
- Open machine controls stay open when plotting begins. Stop remains visible and is disabled when there is no active Gantry operation.
- Calibration and station-test motion buttons disable while disconnected or busy. Disconnecting cannot be undone by a later availability refresh.
- The user guide and actual Swing screenshots document the new behavior. Dark remains the default for new profiles.

Download `Gantry-1.0.0-rc.8-windows-x64.msi` or `Gantry-1.0.0-rc.8-linux-x64.deb`. Both bundle Java. Native version `1.0.8` supports upgrading from RC7 (`1.0.7`). Portable GUI and CLI JARs require Java 17+.

Local targeted regression tests, Dark/Light layouts and mock GUI workflows passed, including pen changes, Stop, imports, save/recovery and wizard cleanup. Release CI runs the full suite, layout checks and Linux/Windows native installer acceptance. Upgrade checks use a synthetic previous-version fixture and verify user-state preservation.

Physical Windows 11 / iDraw H A1 acceptance of changed manual interactions, native Windows scaling acceptance and novice/expert observation remain pending. This is a prerelease; earlier hardware results do not establish acceptance of these changes.
