# Gantry 1.0.0-rc.7

RC7 introduces consistent action colours across the Dark and Light workspaces.
Existing release assets remain unchanged.

- Neutral controls edit artwork or navigate; blue controls prepare or review a job.
- Amber controls can move the machine. Secondary actions use a subtle tint and movement icon; Start, Continue and Resume use a filled amber treatment. Jog buttons retain their direction arrows. Pause is also amber.
- Stop stays red, including wizard operation controls. Green status text indicates verified conditions or successful submission; connection alone does not imply job readiness or physical completion.
- The same scheme covers preflight, calibration, watercolor station tests and raw G-code. Import no longer uses green.
- Disabled controls stay muted. Home and Frame now appear disabled while disconnected or busy, matching their existing execution restrictions.
- Updated user guide and actual Swing screenshots explain the scheme. Dark remains the default for new profiles.

Download `Gantry-1.0.0-rc.7-windows-x64.msi` or `Gantry-1.0.0-rc.7-linux-x64.deb`. Both bundle Java. Native version `1.0.7` supports upgrading from RC6 (`1.0.6`). Portable GUI and CLI JARs require Java 17+.

Local validation passed seven targeted regression tests, actual Swing Dark/Light layouts and the mock GUI workflow including pen changes, Stop, save/recovery and import cancellation. Release CI runs the full suite, layout checks and native installer acceptance on Linux and Windows. Upgrade checks use a synthetic previous-version fixture and verify preservation of user state.

Physical Windows 11 / iDraw H A1 acceptance of the changed manual interactions, native Windows display-scaling acceptance and novice/expert observation remain pending. This is a prerelease; earlier hardware results do not establish acceptance of these changes.
