# Gantry 1.0.0-rc.6

RC6 refines the canvas-first workspace and fixes the SVG → position → pen setup → plot → repeat workflow. Existing release downloads remain unchanged.

- New profiles start in Dark, with a graphite palette, blue accents, quieter controls, clearer property headings and an unboxed layer list. Saved theme preferences remain respected; Light is still available.
- SVG and raster previews reflect physical placement and machine geometry. Cancelled or stale processing cannot apply an obsolete result.
- Artwork placement and undo preserve source data and pen widths. Appending and reprocessing retain identifiable layer settings and flag ambiguous matches.
- Save reuses the current project path. Recovery offers Recover, Discard and Later, and deferred recovery survives closing the application.
- Manual actions remain cancellable through cleanup; repeated Stop is safe. Job outcomes remain visible after disconnect, and document reloads preserve the reported head position.
- Bounds checks explain clipping. Historical jobs can be previewed without replacing the current document, and geometry mismatches block replay.
- Machine-settings import reviews grouped changes before applying them, preserves local presentation preferences and reports persistence failures.
- Pen-change instructions, processing failures and export feedback are clearer. Updated screenshots and the mock-plot demo show the actual Swing application.

Download `Gantry-1.0.0-rc.6-windows-x64.msi` or `Gantry-1.0.0-rc.6-linux-x64.deb`. Both bundle Java. Native version `1.0.6` supports upgrading from RC5 (`1.0.5`). Portable GUI and CLI JARs require Java 17+.

Project formats, CLI interfaces and hardware protocols remain compatible. No connection or job readiness is restored at startup.

## Validation and remaining acceptance

Local validation includes the 522-test Maven suite for the workflow changes, targeted regressions after the visual refresh, actual Swing mock-plot workflows, and Light/Dark layout checks at minimum and larger workspace sizes. Release CI checks both Java versions and native Linux/Windows packaging, installation and upgrade paths. Detailed local evidence and scaling limitations are in `docs/release-results/gui-workflow-implementation.md`.

Fresh Windows 11 / iDraw H A1 physical acceptance, native Windows display-scaling checks, novice observation and the expert workflow review remain pending. Earlier hardware results do not establish acceptance of the changed manual-control interactions. This is a prerelease.
