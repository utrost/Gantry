# Gantry 1.0.0-rc.5

RC5 makes the workspace calmer and reduces the number of permanently visible
buttons. Published RC4 downloads remain unchanged.

- A slim toolbar provides Open / Add, Save, Undo/Redo, connection status and a
  Machine toggle. Appearance controls are in Preferences > Application.
- The empty-canvas hint offers Browse and Close. Escape dismisses it while
  focused, and ordinary refreshes do not bring it back during the session.
- A contextual artwork inspector replaces permanent task tabs. Placement uses a
  compact grid; numeric edits commit on Enter or focus loss and remain undoable.
  Artwork groups expose their own offsets and scale; processing follows source
  availability.
- Layer names and pen-colour swatches are separate. Selecting a layer reveals a
  shared Pen properties action; only its Plot checkbox changes plot inclusion.
- Compact machine controls open on demand. Pin keeps them available across
  selection changes and restarts; Close clears the pin. Job and jogging safety
  gates remain in effect.
- The fixed job strip shows progress and pen-change instructions, with contextual
  Pause/Resume and Stop. Copy Diagnostics and raw commands live inside the drawer.
- Shared styling uses quieter secondary actions, scalable toolbar icons and a
  single primary-action accent, with both Light and Dark themes.

Download `Gantry-1.0.0-rc.5-windows-x64.msi` or
`Gantry-1.0.0-rc.5-linux-x64.deb`. Both bundle Java. Native version `1.0.5` supports
upgrading from RC4 (`1.0.4`). Portable GUI and CLI JARs require Java 17+.

Project files, machine-settings transfer, CLI interfaces and hardware protocols
remain compatible. No connection or job readiness is restored at startup.

Validation evidence is recorded in release CI and the RC5 validation report.
Fresh Windows 11 / iDraw H A1 physical acceptance, novice observation and expert
workflow review remain pending. Earlier hardware results do not establish
acceptance of the changed manual-control interactions.
