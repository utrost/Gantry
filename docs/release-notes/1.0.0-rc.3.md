# Gantry 1.0.0-rc.3

This candidate introduces the redesigned Swing workspace for SVG preparation and
pen plotting. RC2 downloads remain available and unchanged.

- Prepare, Check, Plot and Machine inspectors share one canvas and document.
- Persistent job controls keep Stop accessible during plotting and pen changes.
- Inline automatic checks and transient operator confirmations retain the configured
  preflight policy. Unknown or moving real controllers cannot start a new plot.
- Undoable placement, physical dimensions and an aspect-ratio lock; neutral layer
  labels with separate pen swatches and optional watercolor properties.
- Keyboard jogging requires focus on a manual direction button. Continuous jogging
  ends on release, focus loss, disconnect or task changes.
- System, Light and Dark themes, separate canvas appearance, comfortable/compact
  density, remembered inspector width and a collapsible diagnostics drawer.
- Raster preview, placement and processing share one import confirmation.
- Job messages distinguish submitted commands from confirmed physical completion.

Download `Gantry-1.0.0-rc.3-windows-x64.msi` or
`Gantry-1.0.0-rc.3-linux-x64.deb`. Both include Java. Windows packages are unsigned.
Portable GUI and CLI JARs require Java 17+. Installer metadata uses numeric
version `1.0.3`; application diagnostics report `1.0.0-rc.3`.

Existing projects load with compatible placement defaults. New independently
stretched placements require RC3 or later. CLI interfaces and hardware protocol
are unchanged.

Automated validation includes Java tests, real Swing mock plotting and recovery,
and both themes at 100%, 125%, 150% and 200% scaling. Reference failure screenshots
exercise presentation states; they do not establish physical hardware behavior.
The five-person novice study, expert review with Uwe, and a fresh Windows 11 /
iDraw H A1 check of the redesigned machine interactions remain pending. RC2's
reported hardware success does not constitute hardware acceptance of RC3.
