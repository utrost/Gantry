# Gantry 1.0.0-rc.2

This candidate adds Windows/Linux installers with bundled Java and brings the
post-RC1 plotting improvements to testers. It does not claim broad hardware
readiness.

- Windows x64 MSI installs for the current user, with GUI and offline-help
  Start menu entries. Ubuntu x64 DEB retains its application-menu shortcut.
- Native CLI uses the bundled Java runtime; no separate Java or CLI shortcut.
- Complete offline getting-started guide, screenshots, sample SVGs and license.
- Consistent installer downloads and separate portable JAR/docs downloads.
- Settings, history and recovery use a stable user profile across menu launches.
- About and diagnostics identify the actual candidate version.
- Automated native upgrade and installed-runtime workflow checks preserve
  settings, history and recovery across updates and uninstall.
- Artwork composition, per-layer pen preview and watercolor controls.
- Plot lifecycle, command persistence and homing safety improvements since RC1.

Download `Gantry-1.0.0-rc.2-windows-x64.msi` or
`Gantry-1.0.0-rc.2-linux-x64.deb`. Java is included. Windows installers are
unsigned. Initial desktop targets are Windows 10/11 and Ubuntu 22.04/24.04 x64;
consult the release acceptance record for the combinations actually tested.
GUI/CLI JARs remain available for Java 17+ users.

Installer metadata uses numeric version `1.0.2`; Gantry itself reports
`1.0.0-rc.2`. User profiles are preserved on uninstall. Start with the guided
mock first plot before connecting hardware.

See `release-results/1.0.0-rc.2.md` in the source tree for automated results and
outstanding interactive/hardware acceptance. A draft is not a completed public
release; publish only after reviewing its attached artifacts and evidence.
