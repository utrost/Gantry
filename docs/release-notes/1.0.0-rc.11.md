# Gantry 1.0.0-rc.11

RC11 improves manual-control stability and unavailable-action feedback. Published RC10 and earlier assets remain unchanged.

## Changes

- Manual jogging no longer opens and closes the plot-progress area, avoiding repeated canvas resizing.
- Busy manual controls receive their final enabled state once per refresh, avoiding transient re-enabling and button animation resets.
- Both Frame actions remain visible but disabled without artwork or included pen layers. Plot-review Home machine and Raise pen also require artwork. Tooltips explain unavailable actions; connection and busy-state restrictions remain in effect.
- Preferences now explicitly distinguish Interface theme from Canvas background. Dark remains the interface default; saved preferences are respected.

## Downloads and verification

Windows x64 MSI and Linux x64 DEB include Java. Portable GUI/CLI JARs, offline documentation and checksums are also provided. Native installer version is **1.0.11**.

Local validation: 554 Java tests passed; the desktop mock workflow verifies empty-document action availability and recovery after loading artwork. Regression tests cover stable canvas space during manual operations and busy-control transitions. Release CI runs native Windows/Linux installation and upgrade checks from RC10.

Physical Windows 11/iDraw H A1 verification of the changed interactions remains outstanding; mock checks do not establish hardware acceptance.
