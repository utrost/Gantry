# Gantry 1.0.0-rc.10

RC10 completes a verification pass over the independently testable GUI/workflow
issues from the RC5 audit. It retains RC9's pen-aware fills and project formats.
Published RC9 and earlier downloads remain unchanged.

## Changes

- Reconnecting retains the previous job outcome and disables duplicate connection
  attempts while waiting. Connection preferences stay visible but disabled until
  disconnect; connected simulation status comes from the actual backend.
- Placement rejects incomplete numbers instead of silently accepting a numeric
  prefix. Enter and focus loss commit one edit; Escape restores the last value.
  Invalid property input cannot prevent focusing Stop.
- Historical-job review, bounds, estimates, framing and execution stay attached
  to the stored job while a different drawing is open. Returning restores that
  drawing unchanged. Repeat explicitly identifies current pen/speed settings.
- Reprocessing requires an unambiguous layer mapping in both directions;
  duplicate incoming layers remain excluded for review. Appending the first SVG
  retains its source and processing provenance.
- Export/save results remain visible after an error. An unresolved-error action
  retains the earlier detail, and errors return after temporary notices expire.
  Long messages have accessible details; wrapped review warnings can grow.
  Retained feedback adapts when switching themes.
- Setup preserves unexposed calibration, serial timing and workspace values.
  Failed setup or Preferences persistence leaves active settings unchanged;
  setup failure does not proceed to calibration.
- Wizards report skipped steps and clean up on navigation, Finish, Escape and
  Close. Repeated closing does not issue duplicate cancellation requests.
- SVG dialogs distinguish opening/replacing a drawing from appending artwork.
  Cancelled/superseded raster traces and their temporary metadata are cleaned up;
  the accepted trace remains available for import.
- Plain pen layers can edit width without a refill station. Width-only changes
  preserve drawing and manual refill commands, with coherent Undo/Redo.
- Long requested-pen names wrap. Settings-transfer comparison keeps station
  fields grouped correctly and exposes full values in tooltips. G-code export
  snapshots speed/pen and station settings before the background write.

## Downloads

- Windows x64 MSI and Linux x64 DEB, with Java bundled.
- Portable GUI and CLI JARs for Java 17+.
- Complete offline documentation ZIP, README, license, version and SHA256SUMS.

Native installer version is **1.0.10**, newer than RC9's 1.0.9.
