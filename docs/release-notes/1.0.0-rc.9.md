# Gantry 1.0.0-rc.9

RC9 makes filled areas predictable from effective pen width and optional overlap.

- Calculate physical spacing across SVG/raster import, source reprocessing and region filling, including nonuniform placement and per-colour settings.
- Review round-tip coverage, uncovered gaps and overshoot before applying. Preview changes cancel stale work; Cancel leaves artwork unchanged.
- Keep strokes inside boundaries with a pen-radius inset, preserving holes and reporting narrow features that cannot be filled.
- Save named pen/paper profiles with nominal diameter separate from effective stroke width. Generate labelled 0/10/20/30% calibration swatches as ordinary undoable artwork.
- Retain manual spacing, old project recipes, Dark as the default theme, visible disabled actions and normal machine preflight.
- Refresh the user/developer guides, offline installer help, all current screenshots and the mock first-plot video.

Download `Gantry-1.0.0-rc.9-windows-x64.msi` or `Gantry-1.0.0-rc.9-linux-x64.deb`.
Both bundle Java. Native version 1.0.9 upgrades from RC8 (1.0.8). Portable GUI/CLI
JARs require Java 17+. Previous releases remain unchanged.

Validation includes 537 Java tests, Python packaging checks, mock GUI workflows,
Dark/Light layouts and native installer/upgrade CI. Upgrade fixtures are synthetic
previous-version packages, not a claim of exhaustive historical migration tests.

Generated fills are static: resize first, or regenerate after resizing. Coverage
is a round-tip geometric estimate, not a guarantee of ink behavior. Windows 11 /
iDraw H A1 pen/paper validation and external novice/expert studies remain separate.
Windows installers remain unsigned. This is a prerelease.
