# RC5 workspace validation

## Local automated evidence

- 509 Java tests passed, with no failures or skipped tests.
- 9 Python packaging and release-payload tests passed.
- Swing GUI acceptance passed: machine-settings transfer, cancellation and
  connected-import rejection; SVG import and replacement cancellation; raster
  cancellation; toolbar undo/redo; a focused numeric placement edit committed
  with Enter and reversed in one undo; three-pen mock plotting; repeat job;
  Stop while waiting for a pen; G-code export; project save/reopen; crash recovery.
- Real Swing reference runs passed in Light and Dark at requested Java2D scales
  1, 1.25, 1.5 and 2. Captures cover empty and dismissed hints, prepared and
  selected artwork, machine tools, checks, running, pen change, stopped and
  failure states, plus a larger workspace. Stop bounds are checked during jobs.
- Regression tests cover session-only hint dismissal, pin/navigation behaviour,
  many long-named layers, separation of layer inspection from plot inclusion,
  jog-key focus scope, and connection updates while job controls are locked.
- The native Enter-key check ran on the local desktop. Set
  `GANTRY_GUI_REAL_KEYBOARD=true` when running `scripts/test-gui.sh` on a desktop;
  headless-display CI exercises the formatted-field commit without assuming a
  window manager will grant native focus.
- Updated user-guide screenshots and the one-minute mock walkthrough were
  generated from Swing, not illustrative mockups.

The release workflow builds Linux DEB and Windows MSI packages and runs installed
workflow/RC4-to-RC5 upgrade checks on both platforms. Its GitHub Actions results
are the authoritative installer evidence for the published tag.
