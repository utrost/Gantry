# RC3 workspace validation

The redesign retains Swing/FlatLaf, the command model, CLI and machine backends.
The presentation snapshot is read-only; transient checks are not serialized.
Placement history includes sizing, rotation, mirror and offsets. Older project
placement records default to proportional scale.

## Automated evidence

- 499 Maven reactor tests (zero failures/errors/skips) cover presentation transitions, mandatory checks, placement
  history, independent sizing, controller cancellation and slow pause behavior.
- `scripts/test-gui.sh` exercises real file dialogs, SVG/raster cancellation,
  placement undo/redo, three-pen mock plotting, Stop, export, save/reopen and
  recovery after process restart.
- `scripts/test-workspace-layouts.sh` renders empty, prepared, checking, running,
  pen-change, stopped and failure states in Light and Dark at four scale factors.
  It asserts that active Stop is visible and inside the 1024×800 logical workspace.
  The failure reference is injected into the presentation model, not a hardware test.
- Nine Python packaging regression tests pass.
- Release CI builds MSI/DEB and portable payloads, and tests installed workflows
  and upgrading from RC2. CI artifacts contain the detailed reports.

## Human acceptance still required

- Five-person novice study: at least four complete a mock plot without procedural
  help, and all correctly identify connection and movement state.
- Uwe's expert workflow: positioning, pen setup, plotting and repeat jobs require
  fewer inspector switches without mandatory additional guidance.
- Windows 11 / iDraw H A1: repeat the changed jogging, pause/stop, alarm/disconnect
  recovery, home/frame, limits/calibration and actual plotting checks.
- Native Windows/Linux display, keyboard-only and assistive-technology review.
  Automated Linux scaling captures do not substitute for native Windows DPI tests.

RC2 assets are not replaced. This remains a release candidate until the human
acceptance work is complete.
