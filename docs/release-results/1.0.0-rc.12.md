## Visual quality finding — #93

**FAIL: readable orientation / agreement between views.** The default-profile
10 mm “Max Mustermann” label is vertically reflected in the workspace; SVG and
heatmap use the motor grid as an unconditional X-right/Y-up page and show a
horizontal reflection. The observed views differ. These captures are defect
evidence, not accepted artwork examples:

- [Workspace and export feedback](../images/workspace/quick-artwork.png).
- [Ink overlap](../images/workspace/ink-overlap.png).
- [#93 source analysis and acceptance](https://github.com/utrost/Gantry/issues/93).
- [Four-origin diagnostic and measured matrix](../validation/orientation/README.md#four-origin-diagnosis).

The document generator and SVG importer use Y-up coordinates, while the ordinary
origin-derived workspace mapping displays document Y downward. Export/heatmap
also omit the origin/axis projection needed for the physical-page view. Fixing
this requires compatibility review: globally flipping axis defaults would change
G-code for existing calibrated profiles. No motion settings were changed during
release preparation. Keep public distribution on hold until #93 is resolved or
explicitly dispositioned; automated workflow passes do not override this finding.

The 16 virtual runs requested scales 1 / 1.25 / 1.5 / 2 and observed device
transforms 1 / 1 / 1 / 2. They do not establish native fractional scaling. The
three-photo standard corpus (12 combinations, twice) and actual Studio Squiggle
preset (three combinations, twice) retained all reviewed geometry hashes and
passed production G-code preflight with the versioned candidate CLI.
