# RC10 validation — 2026-11-14

## Scope

RC10 completes the independently testable GUI/workflow issues from the RC5 audit.
The [issue acceptance matrix](rc10-workflow-issues.md) maps each fix and previously
implemented behavior to regression evidence. Published RC9 assets are preserved.

## Local evidence

- Maven package: 552 Java tests, no failures, errors or skips.
- Python packaging regression: nine tests, including offline payload and relative links.
- Native Linux Swing: mock plotting, pen changes, Stop, save/recovery, SVG/raster import, wizard lifecycle, direct practice and settings persistence failures.
- Historical A/current B: preview, estimate, frame, requested pen and execution stay attached to stored A; returning restores B unchanged.
- Native keyboard: unique repeat/reprocess shortcuts, numeric Enter/Tab/Escape and explicitly focused jogging. A production mouse event starts the held-jog check; real focus loss cancels it. No physical hardware is connected.
- Rendered button text: default, primary, motion, Stop and selected toggles in normal/hover/pressed/native-focus states through Dark → Light → Dark meet 4.5:1. Hover and pressed states use button models.
- Layout matrix: Light/Dark and both densities at 1024×800 and 1440×1000. Requested 125%/150% resolve to an effective 100% device transform locally; at 200%, the physical display limits the window to 703 logical pixels high. These cases are recorded as unavailable native-scaling evidence, not passes of the 800-pixel acceptance criterion.
- Current screenshots and captioned mock walkthrough are generated from actual Swing components in isolated profiles.

Reproduce with the commands in the [issue matrix](rc10-workflow-issues.md).

## Delivery evidence

[PR #64](https://github.com/utrost/Gantry/pull/64) contains this pass. Its
[checks](https://github.com/utrost/Gantry/pull/64/checks) provide Java 17/21,
GUI and native packaging logs with downloadable validation artifacts. The
[RC10 release](https://github.com/utrost/Gantry/releases/tag/v1.0.0-rc.10)
contains the resulting downloads and consolidated checksums.

The release workflow builds Windows x64 MSI and Linux x64 DEB with bundled Java,
portable GUI/CLI JARs, offline documentation and consolidated SHA256SUMS. Native
version is **1.0.10**. Upgrade validation uses a **synthetic RC9 fixture** and
checks retained user state; it is not a manual upgrade of the previously
published RC9 installer.
