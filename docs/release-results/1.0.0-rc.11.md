# RC11 validation — 2026-11-15

RC11 is a published prerelease. It stabilizes the manual-control layout and
disables Frame and plot-review actions when the required artwork is absent.
See the [release notes](../release-notes/1.0.0-rc.11.md) and
[published assets](https://github.com/utrost/Gantry/releases/tag/v1.0.0-rc.11).

## Automated evidence

- The [CI run](https://github.com/utrost/Gantry/actions/runs/43643382775)
  completed successfully on the RC11 commit `c630f27`; the release notes record
  554 passing Java tests and desktop mock-workflow/regression coverage.
- The [release-installer run](https://github.com/utrost/Gantry/actions/runs/43643388431)
  completed successfully on the same commit. It builds native Windows and Linux
  packages and runs installation, upgrade and installed-workflow checks.
- The published prerelease contains a Windows x64 MSI, Linux x64 DEB, portable
  GUI and CLI JARs, offline documentation ZIP, standalone README, license,
  version file and checksums.

## Acceptance limits

- The automated GUI workflow uses a mock plotter. It does not establish physical
  Windows 11 / iDraw H A1 acceptance of the RC11 control changes.
- The core workspace screenshots were refreshed from the RC11 GUI CI artifact
  on 2026-11-15. Supporting screenshots and the mock walkthrough were captured
  from RC10 on 2026-11-14, and do not show RC11's changed control states.
- Windows installers remain unsigned. External novice/expert testing, broader
  hardware coverage and physical pen/paper evaluation remain open.
