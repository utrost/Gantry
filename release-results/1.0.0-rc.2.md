# Gantry 1.0.0-rc.2 acceptance record

This is a preparation record, not a claim that RC2 has been publicly released.
Implementation is reviewed in https://github.com/utrost/Gantry/pull/28.

## Local evidence (2026-09-26)

Host: Ubuntu 24.04 x86-64, OpenJDK 17.0.20.1, Maven 3.9.9.

- [x] Full clean release build: 462 Java tests, zero failures/errors/skips.
- [x] Migration tests: legacy history/recovery, preservation of newer state,
  no resurrection after recovery dismissal, isolated explicit profile.
- [x] Two packaging tests: RC-to-stable numeric ordering and invalid versions.
- [x] GUI/CLI JARs contain `Implementation-Version: 1.0.0-rc.2`.
- [x] CLI artifact `--help` smoke check.
- [x] Linux DEB produced with launcher, runtime and desktop entry.
- [x] Extracted Linux native launcher created a visible Swing window and
  reported `1.0.0-rc.2` with Java-related environment variables removed and no
  system Java on PATH. This used a temporary mock profile and exited normally.
- [x] SHA-256 verification for every locally staged asset.

The local DEB uses the host's Ubuntu 24.04 library baseline. Prefer the CI
Ubuntu 22.04 package for distribution; it is built on the older baseline.
